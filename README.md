# Blütenpost — Thumbnails

Bildablage für die YouTube-Uploads des Kanals Blütenpost (@blutenpost).
Die Dateien werden über `raw.githubusercontent.com` von YouTube abgeholt und
dürfen deshalb nicht umbenannt oder gelöscht werden, solange geplante Posts
darauf zeigen.

Geändertes Bild immer unter NEUEM Dateinamen ablegen — raw.githubusercontent
cacht aggressiv, eine ersetzte Datei kommt minutenlang in der alten Fassung.
